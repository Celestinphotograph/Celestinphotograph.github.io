# Celestin Photograph · 摄影图片社网站

一个纯静态的摄影作品展示网站，托管于 GitHub Pages，无需后端与数据库。
页面样式严格按设计稿复刻：双栏顶栏、首页大图+滚动图集、分类长页、竖/横两种图集查看器、背景模糊、文字说明窗口。

## 项目结构

```
Celestinphotograph.github.io/
├── index.html          # 页面骨架（一般不用改）
├── css/
│   ├── base.css        # 全局变量、双栏顶栏、导航、页脚、更多面板、响应式
│   ├── home.css        # 首页：大图区 + 横向滚动图集区
│   ├── category.css    # 分类页：长页图集列表、右下角张数
│   └── viewer.css      # 图集查看器：竖/横排版、背景模糊、文字窗口
├── js/
│   ├── core.js         # 启动、路由、双栏箭头、滚动收起、更多面板
│   ├── home.js         # 首页渲染与滚动区交互
│   ├── category.js     # 分类页渲染
│   ├── viewer.js       # 查看器：打开/切换/键盘/触摸/自动隐藏
│   └── app.js          # 程序入口（引导启动）
├── data/
│   └── site-data.js    # ★ 站点数据配置（增删改图片/分类/图集都改这里）
├── assets/
│   ├── favicon.png     # 网站图标
│   └── icons/          # 顶栏箭头图标
└── images/             # 你的图片文件夹（按图集建子目录，如 images/city-frame/）
```

- **HTML、CSS、JavaScript、数据完全分离**：日常只改 `data/site-data.js` 一个文件即可维护全站内容，不需要懂代码。
- 图集标题、分类名等所有文字都由数据文件统一驱动：改一处标题，首页、分类页、详情查看器自动同步。

## 如何添加 / 修改图片（只需编辑 data/site-data.js）

打开 `data/site-data.js`，文件里每一段都是**一个图集**：

```js
{
    id: "city-frame",            // 图集编号（英文/拼音，不要重复，别改动）
    title: "城市的框架",          // 图集名称（全站同步）
    category: "street",          // 所属分类（填下方 categories 里的 key）
    photographer: "Celestin",    // 摄影师
    year: "2025",                // 年份
    description: "…",            // 简介（可留空 ""）
    location: "上海",            // 拍摄地点（可选字段，示例）
    cover: "images/city-frame/01.jpg",   // 封面（可选；不填则用第一张）
    images: [                    // 图片列表：可加任意多张
        { url: "images/city-frame/01.jpg", caption: "这张图的文字说明（可留空，留空显示占位符）" },
        { url: "https://example.com/02.jpg", caption: "" }
    ]
}
```

- **新增图集**：复制上面一整块，粘贴到 `albums` 数组里（最后一个 `}` 之前），改内容。
- **新增分类**：在文件顶部的 `categories` 数组加一行 `{ key: "xxx", name: "分类名" }`，再让图集引用该 key。分类会自动出现在顶部导航。
- **新增字段**：直接在某个图集里加一行，如 `location: "北京"`，不影响其它功能；页面不认识的新字段会被自动忽略，方便未来扩展（比如"拍摄地点"）。
- **图片地址**：
  - 网络图片：直接填完整网址。
  - 仓库内图片：把图片放进 `images/` 文件夹，填相对路径 `images/子目录/文件名.jpg`。
- **首页版面**：`home.sections` 数组控制首页从上到下的展示顺序。`featured` = 大图区，`scroller` = 横向滚动图集区。可增删、调整顺序，形成"大图 → 滚动 → 大图 → 滚动"的版式。

## 页面交互

- 左上角箭头：展开 / 收起第二栏顶栏（记住状态，滚回顶部时保持）。
- 滚轮向下：收起两栏顶栏展示更多内容；滚轮向上：恢复顶栏。
- 右上角按钮：更多信息面板（内容占位，可自行扩展）。
- 首页 / 分类页点击图集封面：打开查看器。
- 查看器：
  - 白色面板居中显示、尺寸较大（桌面 3:2 / 移动端 3:4），横图/竖图切换时面板不变。
  - 照片只占白色面板左侧约 60%（靠左，不顶满），右侧留白放置标题/张数/文字说明；面板外为压暗的模糊背景。
  - 竖图标题在右上、横图标题在左下，张数始终在右下，文字说明固定在面板内右侧留白处（垂直居中）。
  - 打开/关闭时面板与图片整体做基本渐显/渐隐（模糊同时从无到有平滑过渡）；左右切换图片为硬切、无过渡。
  - 鼠标移动显示左右切换键，静止后自动隐藏；鼠标悬浮在切换键上保持常显；首次打开短暂提示。
  - 点击面板（含照片/文字）不关闭查看器，点击面板外背景关闭；键盘 ←/→ 切换、Esc 关闭、浏览器返回键关闭。
  - 移动端：左右滑动切换图片（不显示切换键）。
- 页面适配手机 / 平板 / 电脑。

## 部署到 GitHub Pages

1. 把整个文件夹（`index.html`、`css/`、`js/`、`data/`、`assets/`、`images/`）推送到你的 GitHub 仓库 `Celestinphotograph.github.io`。
2. 进入仓库 Settings → Pages → 在 "Branch" 选择 `main` 并保存。
3. 稍等片刻，访问 `https://Celestinphotograph.github.io/` 即可看到网站。

## 常见问题

- **改了数据但页面没变化？** 浏览器缓存导致。在 GitHub Pages 上强制刷新（Ctrl+Shift+R / Cmd+Shift+R）；或把 `index.html` 里资源链接的 `?v=6` 改成 `?v=7`（每次更新资源后 bump 一下即可，也可改成任意新数字）。
- **想加更多交互？** 逻辑已按模块拆分在 `js/` 下并带注释，可自行扩展；页面结构在 `index.html`。
